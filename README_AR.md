# English 6th Prep 2027 — مشروع Android

## ما الموجود في هذه النسخة؟
- مشروع Android Studio يستخدم WebView لعرض واجهة محلية داخل التطبيق.
- الواجهة والبيانات محفوظة داخل `app/src/main/assets` وتعمل دون اتصال.
- اختيار وضع الأستاذ أو الطالب.
- فهرس أولي للوحدات الثماني.
- قائمة موضوعات القواعد والأدب.
- عرض توزيع درجات نموذج الامتحان التجريبي المرفق بالخريطة.
- اختبار مفردات تجريبي قصير، مع حفظ عدد المحاولات محلياً.

## بناء APK
1. افتح مجلد المشروع في Android Studio حديث.
2. اسمح له بتنزيل Android Gradle Plugin وAndroid SDK Platform 35 عند الطلب.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ملف APK الناتج يظهر عادة في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات مهمة حول دقة المحتوى
- توزيع الدرجات المعروض مأخوذ من نموذج الامتحان التجريبي المصوّر في ملف «اسئلة+خريطة + الدرجات.pdf»: القراءة 20، القواعد والوظائف 30، المفردات والإملاء 20، الأدب 15، الكتابة 15. لا يُعرض باعتباره تعميماً وزارياً مؤكداً.
- قائمة الموضوعات والوحدات هي فهرسة أولية. يلزم استكمال تفريغ جميع صفحات الملازم وكتاب النشاط قبل اعتبار المحتوى شاملاً.
- أمثلة الأسئلة الأربع مأخوذة من ملاحظات ومفردات ظاهرة في المواد المرفوعة، وهي تدريب أولي وليست أسئلة وزارية.
- هذا الإصدار لا يتضمن بعد تسجيل دخول حقيقياً، مزامنة سحابية، أو نظام تحديث تلقائي. التحديث المستقبلي يحتاج خدمة محتوى/خادم أو استيراد حزمة بيانات موقعة.
- اختيار وضع الأستاذ/الطالب في النسخة الحالية للتنقل فقط وليس نظام صلاحيات آمناً.
